Docs-as-Code の実践と成果

Keywords : Markup, SSG, VersionControl, CI/CD

ドキュメントをソフトウェアのソースコードと同様に扱う「Docs-as-Code」の具体的な実装アプローチです。

構築したパイプラインの特長

  1. プレーンテキストによる記述:
    Markdown および Asciidoctor を採用し、DTP ツールへの依存を脱却。
  2. 完全な構成管理:
    GitHub でのブランチ管理 ・ Pull Request ベースのレビューフローとのシームレスな統合。
  3. マルチパブリッシング:
    1 つのソースから、Web ポータル (静的サイト) と印刷用 PDF を自動的に出力する仕組み。

テクニカルスキル

  • Markup: Asciidoctor, AsciiDoc, Markdown, HTML/CSS
  • SSG/Tools: Antora, 静的サイトジェネレーター
  • Version Control: Git, GitHub
