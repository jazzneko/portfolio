キャリアヒストリー (直近 15 年の実績)

Keywords : 3D-CAD, PointCloud, Documentation, ProductManagement

製造・建設テック領域における、高度な 3D データ処理システム (CAD データ変換システム、および三次元点群データシステム) のユーザー・開発者向けマニュアル全般の制作、およびドキュメント生成基盤の刷新と運用を 15 年間担当。

担当業務における 3 つの高度な専門性

  1. 技術的専門性 : 複数のツールや技術を理解し、連携させる能力

    Asciidoctor と Antora を組み合わせたドキュメント生成環境を自ら設計・構築。 開発チームが統括する GitHub による差分管理や Pull Request ベースのレビューフローとも柔軟に連携させ、開発サイクルと同期したドキュメント運用基盤を確立しました。

  2. 設計能力 : マニュアル制作工程や情報構造を全体から設計する能力

    各種マニュアル間で重複する共通手順やシステム仕様を部品化 (コンポーネント化)。 Antora のマルチリポジトリ構造を活かし、最小限の修正で全ドキュメントへ自動反映される再利用性の高いデータモデルを設計しました。

  3. 問題解決・推進能力 : 前例のない技術を調査・導入し、障害を解決しながら運用を継続する能力

    従来の Word や専用 DTP ツールによる管理から脱却し、属人化の解消と運用コストの大幅削減に成功。 製品アップデートに追従し、15 年間一度も破綻させることなく安定運用を継続してきました。

    3D 空間の座標処理やデータ変換時の欠損対策など、高度な仕様をエンドユーザーが直感的に理解できるよう、元 3D モデラー・元サポートエンジニアとしての知見を活かしたステップバイステップのチュートリアルを執筆。 前例のない Docs-as-Code 体制を破綻なく定着させました。

主な実績・成果

  • 属人化の解消と運用コストの削減: Word 等のバイナリ管理からテキストベース (Asciidoctor) ＋Git 管理へ移行。レイアウト崩れの修正やバージョン管理の手間を排除。

  • コンポーネント化によるメンテナンス性の向上: 重複コンテンツを共通化し、製品アップデート時の多重修正・修正漏れミスをゼロに削減。

  • サポートコストの削減: ユーザーがつまずきやすいエラー対処を徹底的に構造化・チュートリアル化した結果、サポートへの初期問い合わせ数を削減。
